# Schrodinger-s_Kittens
Schrodinger's Kittens is a quantum computing spin on the Exploding Kittens game.

# Setup Information
To run the game locally: clone the repo to your local machine, then run Schrodinger_Kittens_Playground.ipynb to completion.
To run the game on Colab: download and run Schrodinger_Kittens_Playground_Colab.ipynb to completion.
Note: The Visual GUI of the qubits cannot be rendered properly within Colab; we recommend you run this game locally to get the full experience.
